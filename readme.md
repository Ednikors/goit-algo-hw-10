# Обчислення визначеного інтеграла методом Монте-Карло

## Опис завдання

Обчислення значення визначеного інтеграла функції `f(x) = x²` на інтервалі `[0, 2]` за допомогою методу Монте-Карло та порівняння результату з аналітичним розрахунком і функцією `quad` бібліотеки SciPy.

## Метод Монте-Карло

Метод Монте-Карло базується на статистичному підході до обчислення площі під кривою:

1. Створюємо прямокутник, що обмежує область інтегрування
2. Генеруємо велику кількість випадкових точок у цьому прямокутнику
3. Підраховуємо частку точок, що потрапили під криву
4. Площа під кривою ≈ (кількість точок під кривою / загальна кількість) × площа прямокутника

## Результати обчислень

| Метод | Результат | Похибка |
|-------|-----------|---------|
| Метод Монте-Карло (100 000 точок) | 2.678320 | 0.4370% |
| Аналітичний метод (∫x²dx = x³/3) | 2.666667 | - |
| Функція quad (SciPy) | 2.666667 | ±2.96e-14 |

## Аналітичне рішення

Для функції `f(x) = x²`:

```
∫₀² x² dx = [x³/3]₀² = 8/3 - 0 = 2.666667
```

## Висновки

1. **Точність методу Монте-Карло**: Метод показує абсолютну похибку 0.011653 та відносну похибку 0.4370% при використанні 100 000 випадкових точок, що є прийнятним результатом для статистичного методу.

2. **Порівняння з аналітичним рішенням**: Результат методу Монте-Карло (2.678320) близький до точного аналітичного значення 2.666667 (8/3), що підтверджує коректність реалізації алгоритму.

3. **Порівняння з функцією quad**: Функція `quad` з бібліотеки SciPy дає значно точніший результат (похибка ~10⁻¹⁴), оскільки використовує адаптивні квадратурні формули замість статистичного підходу.

4. **Залежність від кількості точок**: Точність методу Монте-Карло зростає зі збільшенням кількості випадкових точок. Похибка зменшується пропорційно до √n, де n — кількість точок.

5. **Переваги методу Монте-Карло**:
   - Простота реалізації
   - Універсальність (працює для складних функцій та багатовимірних інтегралів)
   - Легко паралелізується

6. **Недоліки методу Монте-Карло**:
   - Відносно повільна збіжність
   - Результат є випадковою величиною (кожен запуск дає трохи інший результат)
   - Для високої точності потрібна велика кількість точок
